# Momentum 정규 & 방학세션 과제 제출가이드

본 제출가이드는 Momentum n기 정규 & 방학세션의 주차별 과제 제출 시 참고하시면 됩니다.

## 1. 과제 제출 규칙

**안전한 코드 관리와 원활한 피드백을 위해 다른 팀원의 폴더나 공통 파일(README.md 등)은 수정하시면 안 됩니다.**

## 2. 과제 제출 및 확인 기한

- 제출 마감: 목요일 18시 00분 세션 시작 전
- 제출 확인: 운영팀에서 과제가 있는 주차 금요일에 PR을 확인하고 리뷰(의견)를 남기거나 병합(Merge)하여 과제 제출을 확인합니다.
- 부원별로 해야 할 것: 매주 토요일, 본인의 과제가 정상적으로 병합(Merge)되어 제출 완료되었는지 확인합니다.

## 3. [중요] 과제 제출 가이드 (진행 순서)

과제 제출은 반드시 본인의 브랜치를 생성하여 Pull Request(PR)를 진행하는 방식으로 제출합니다. 작업 환경에 따라 아래의 두 가지 방법 중 하나를 선택하여 진행해 주세요.

### 방법 A: 로컬 환경 (VSCode, 터미널 등) 사용자

1. 로컬 환경에 레포지토리 클론
```bash
git clone https://github.com/Momentum-Research-Team/session-assignment.git
```

2. 본인 작업용 브랜치 생성 및 이동
```bash
# 예시: 1주차 홍길동 브랜치 생성
git checkout -b week1-hong
```

3. 과제 폴더 생성 및 파일 업로드
- 해당 주차 폴더(예: `n기 방학세션/1주차/`) 내부로 이동합니다.
- 본인 이름으로 폴더를 생성합니다. (예: `n기 방학세션/1주차/홍길동/`)
- 폴더 내에서 직접 과제를 수행하거나, 작업한 과제 파일을 해당 폴더에 넣습니다.

4. 변경 사항 추가(Add) 및 커밋(Commit)
```bash
# 본인 폴더의 변경 사항만 추가 (예시)
git add "n기 방학세션/1주차/홍길동"

# 커밋 메시지 작성 (예시)
git commit -m "docs: 1주차 홍길동 과제 제출"
```

5. 원격 저장소에 푸시(Push)
```bash
# 생성했던 본인 브랜치 이름으로 푸시합니다
git push origin week1-hong
```

6. Pull Request (PR) 생성
- 푸시를 완료한 후, GitHub 레포지토리 웹사이트에 접속합니다.
- 상단에 활성화된 `Compare & pull request` 버튼을 클릭하여 PR을 생성하면 제출이 완료됩니다.

---

### 방법 B: 구글 코랩(Colab) 사용자

구글 코랩에서 작업하신 경우, 터미널 명령어 없이 코랩의 자체 기능이나 깃허브 웹사이트를 통해 쉽게 제출할 수 있습니다.

**옵션 1: 깃허브 웹사이트에서 직접 업로드 (가장 추천)**
1. 코랩에서 `파일` -> `다운로드` -> `.ipynb 다운로드`를 클릭하여 과제 파일을 내 컴퓨터로 다운로드합니다.
2. GitHub 레포지토리 웹사이트에 접속합니다.
3. 좌측 상단의 브랜치 선택 버튼을 눌러 본인의 브랜치(예: `week1-hong`)를 입력하고 `Create branch`를 클릭하여 새로 생성합니다.
4. 생성한 브랜치에서 해당 주차 폴더(예: `n기 방학세션/1주차/`)로 이동한 후 우측 상단의 `Add file` -> `Create new file`을 누릅니다.
5. 파일명 입력 칸에 `홍길동/.gitkeep` (본인이름/.gitkeep) 이라고 입력하고 커밋(Commit)하여 본인 폴더를 생성합니다.
6. 생성된 폴더 내부에서 다시 `Add file` -> `Upload files`를 눌러 다운로드해 둔 코랩 파일을 업로드하고 커밋합니다.
7. 레포지토리 메인 화면으로 돌아가 `Compare & pull request` 버튼을 클릭하여 PR을 생성합니다.

**옵션 2: 코랩에서 GitHub으로 직접 저장**
1. 코랩 상단 메뉴에서 `파일` -> `GitHub에 사본 저장`을 클릭합니다.
2. GitHub 계정을 연동하고 대상 레포지토리(`Momentum-Research-Team/session-assignment`)를 선택합니다.
3. 브랜치(Branch) 란에 새로 생성할 본인 브랜치 이름(예: `week1-hong`)을 입력합니다.
4. 파일 경로(File path)를 정확히 지정합니다. (예: `n기 방학세션/1주차/홍길동/홍길동_방학1주차_과제.ipynb`)
5. 확인을 누르면 지정한 브랜치와 경로로 파일이 푸시됩니다.
6. GitHub 웹사이트에 접속하여 `Compare & pull request` 버튼을 클릭해 PR을 생성합니다.
